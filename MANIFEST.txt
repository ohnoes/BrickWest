🔌 API ENDPOINTS (Ready to use)
────────────────────────────────────────────────────────────────────────────

  POST   /api/auth/register         Register brewmaster
  POST   /api/auth/login            Get JWT token

  GET    /api/batches               List batches (filterable)
  POST   /api/batches               Create batch
  GET    /api/batches/:id           Get batch
  PUT    /api/batches/:id/status    Update status
  POST   /api/batches/:id/logs      Log reading
  GET    /api/batches/:id/logs      Get history

  GET    /api/recipes               List recipes
  POST   /api/recipes               Create recipe
  GET    /api/recipes/:id           Get recipe
  PUT    /api/recipes/:id           Update recipe
  DELETE /api/recipes/:id           Delete recipe

  GET    /api/team/tasks            List tasks
  GET    /api/team/shifts           View shifts

  WebSocket: Real-time batch updates

💾 DATABASE SCHEMA
────────────────────────────────────────────────────────────────────────────

  users
    id, email (unique), password_hash, name, role, created_at, updated_at

  recipes
    id, brewer_id, name, style, target_abv, target_ibu, volume_liters,
    ingredients (JSONB), notes, version, created_at, updated_at, deleted_at

  batches
    id, brewer_id, recipe_id, batch_number (unique), brew_date, 
    volume_produced, status, notes, created_at, updated_at, deleted_at

  batch_logs (time-series)
    id, batch_id, phase, temperature, gravity, ph, notes, measured_at,
    created_at (indexed on batch_id and measured_at)

  Indexes: Optimized for time-series queries, batch filtering, user lookups
