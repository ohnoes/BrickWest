🚀 QUICKEST PATH TO RUNNING (5 MINUTES)

Option A: Railway Cloud (No setup needed)
────────────────────────────────────────────
1. Go to railway.app → Sign in with GitHub
2. Create Project → Deploy from GitHub
3. Select this repo
4. Add PostgreSQL plugin
5. Deploy
6. Get live API URL → Done! ✅

API lives at: https://your-project.up.railway.app/api

Option B: Local Machine (if you have Node.js)
────────────────────────────────────────────
cd backend
npm install
npm run dev

API lives at: http://localhost:3001

Option C: Docker (if you have Docker installed)
────────────────────────────────────────────
docker-compose -f docker/docker-compose.yml up -d

API lives at: http://localhost:3001

🔌 API ENDPOINTS (20+)

Authentication
  POST   /api/auth/register       Register brewmaster
  POST   /api/auth/login          Get JWT token

Batches
  GET    /api/batches             List batches
  GET    /api/batches/:id         Get batch details
  POST   /api/batches             Create batch
  PUT    /api/batches/:id/status  Update phase
  POST   /api/batches/:id/logs    Log reading
  GET    /api/batches/:id/logs    Get history

Recipes
  GET    /api/recipes             List recipes
  GET    /api/recipes/:id         Get recipe
  POST   /api/recipes             Create recipe
  PUT    /api/recipes/:id         Update recipe
  DELETE /api/recipes/:id         Delete recipe

Team (placeholder for expansion)
  GET    /api/team/tasks          List tasks
  POST   /api/team/tasks          Create task
  GET    /api/team/shifts         View shifts

Real-time
  Socket.emit('join_batch', batchId)
  Socket.on('fermentation_update', data)

💾 DATABASE SCHEMA

users
├── id (PK)
├── email (UNIQUE)
├── password_hash
├── name
├── role (brewer, head_brewer, admin)
├── created_at
└── updated_at

recipes
├── id (PK)
├── brewer_id (FK)
├── name
├── style
├── target_abv, target_ibu
├── volume_liters
├── ingredients (JSONB)
├── version (tracks updates)
└── deleted_at (soft delete)

batches
├── id (PK)
├── recipe_id (FK)
├── batch_number (UNIQUE)
├── brew_date
├── volume_produced
├── status (milling→mashing→boiling→cooling→fermenting→packaging→complete)
├── created_at
└── deleted_at (soft delete)

batch_logs (time-series)
├── id (PK)
├── batch_id (FK, indexed)
├── phase
├── temperature (°C)
├── gravity (SG)
├── ph
├── notes
├── measured_at (indexed)
└── created_at
